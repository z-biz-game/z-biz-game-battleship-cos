# 海战推演 · Battleship Logic（零猜测行列船格推理）

> *题面只告诉你每一行、每一列躺着几个船格。哪几格、船怎么摆，全靠七条铅笔规则推出来——
> 每一局在出货前都被推到底过一次，唯一解由第二套互不信任的穷举计数器逐格复核。*

浏览器原生的**单人海战推理盘**（Battleship Logic / 行列船格 clues）：无构建步骤、无打包器、
**零美术与音频文件**——船体、水波、线索数字、绿环全部 canvas 现画，音效由 WebAudio 合成。

玩法：舰队长度题面给定，把每条船摆进 `w×h` 的海里。船是直线一段、横竖都行、不能拐弯，
**船与船连对角都不许碰**；行/列旁的数字写着这条线里**船格的个数**（不是船的条数），
空白菱形 ◆ 表示这条线题面没给数。**没点过的格子就是水**——把每条船放对即胜，不必把海点满。

- **核心承诺 1｜零猜测**：出货的每一局都能 **只用那七条规则从空盘推到底**。这不是文案，是准入门槛——
  推不到的盘在生成阶段就被拒绝（`craft()` 每抹一条线索都重跑一遍铅笔路径，推不动就把这条放回去）。
- **核心承诺 2｜唯一解**：`countSolutions()` 是一台**不含任何推理规则**的逐格穷举计数器。
  它和铅笔路径从两个方向回答同一个问题；超预算的盘被判 `OVERBUDGET` **直接淘汰，不出货**，
  所以"这一局唯一解"在交付的每一局上都是被证完的，不是"没证完先算过"。
- **核心承诺 3｜提示不是答案**：提示走的是**同一个** `nextDeduction()`，所以它必须点名用了哪条规则、
  落在哪一格（`6 号船在这一盘只剩这一处放得下：第2行第3列 起`）；玩家已经和题面矛盾时，
  提示**拒绝落子也不计入求助次数**，只把矛盾说给你听。
- **核心承诺 4｜推理机不会乱写**：`tools/engine-test.mjs` 的头一条不是"能推完"，而是
  **每一步推论都必须和出题那支舰队对得上**——把生成器的正解当裁判，任何一条规则写错一格就红。
  这一条抓的是"推错了"，比"推不动"值钱。
- 难度不是标签：`初学 → 大师` 五档的分数带是**实测**出来的（`npm run balance` 打印分位表 + 漂移门禁），
  最大档只到 7×7，**为什么不能更大是量出来的**，写在 `js/engine/generate.js` 的档位表上方。
- 规模：**10 个 ES Module / 2,470 行 JS** + 4 个验证脚本 979 行 + `verify.sh` 134 行 + 302 行 CSS/HTML，
  **运行时依赖 0 个**。
- 验证：**引擎不变量全绿**（七条规则的 soundness 探针 / 10 组独立计数对账 / 466 处单格改动逐一答复 /
  五档出题 6/6）+ **119 项浏览器断言**（10 个场景，读 DOM 几何与画布像素，不读标志位）。
- **在线试玩**：<https://z-biz-game.github.io/z-biz-game-battleship-cos/>（`main` 分支推送即自动部署）

## 玩法

| 操作 | 行为 |
|---|---|
| **拖动** | 沿路把经过的格子刷成当前那支笔；一笔算一步 |
| **同笔再点一次** | 变成橡皮——铅笔在纸上点两下，第二下就是把墨去掉（这一步也计步） |
| **船格 / 水格 / 循环** | 三档笔（或 `1` `2` `3`）：循环笔走 未定 → 船 → 水 → 未定 |
| **提示**（或 `H`） | 给出当前推得出的一格，点名规则；这一步真的落子，也真的计入求助次数 |
| **撤销**（或 `Z`） | 退掉一整个手势——一笔刷过的格子一起回来；**步数退，求助次数不退** |

判胜用的是 `verify()`：只读盘面，按规则原文核对"舰队长度多重集对不对得上、船段是不是直线、
两船有没有相接（含对角）、每条给出的行列数数不数得对"。它不读推导脚本也不读 UI 记账，
所以**提示逻辑写错也伪造不出一场胜利**。

## 七条规则（提示只会说这些）

| 规则 | 说什么 | 权重 |
|---|---|---|
| 邻格即水 | 这一格已是船体的一部分 → 它八邻全是水 | 1.0 |
| 满额即水 | 这一行/列的船格数已经数满 → 剩下的未定格都是水 | 1.2 |
| 差额占满 | 还差 k 个船格而只剩 k 格可放 → 那 k 格必须躺着船 | 1.8 |
| 线内排法 | 这一行/列剩下的船格只有那几种排法 → 取交集 | 2.2 |
| 无处落船 | 剩下某艘船没有一种摆法能盖到这里 → 这里必是水 | 2.8 |
| 唯一船位 | 这艘船在这一盘只剩一处放得下 | 3.8 |
| 反证 | 假设这一格是船（或水），剩下的舰队就摆不完 → 反面成立 | 6.0 |

前三条只数**一条线自己的账**，后四条看的是**舰队落得下落不下**——它们全是**必要条件**：
真解既然存在，就必须满足它，所以规则落下的每一格在该盘面的**每一个解**里都成立。
这是"零猜测"得以成立的原因，也是玩家按规则写下的墨不会被冤枉（见 DESIGN §5、§6）。

## 难度是量出来的

`npm run balance`（每档 24 个种子，2026-09-27，空载机器；CI 跑的就是这一档配置）：

| 档 | 盘面 | 舰队 | 留多少线索 | 分数带（选取目标） | 实测中位 | 命中 | 平均抽几次（最坏） | 出题 p95 | 最慢 |
|---|---|---|---|---|---|---|---|---|---|
| 初学 | 4×4 | 3/2/1 | 75% → 6.0/8 | 12–17 | 14.2 | 24/24 | 4.3（12/25） | 113 ms | 187 ms |
| 上手 | 5×5 | 4/3/2 | 70% → 7.0/10 | 22–29 | 25.8 | 24/24 | 1.5（4/20） | 176 ms | 229 ms |
| 熟练 | 6×6 | 4/3/2/1 | 60% → 7.9/12 | 27–36 | 31.6 | 24/24 | 7.0（25/30） | 1,136 ms | 1,505 ms |
| 高阶 | 7×7 | 5/4/3/2/1 | 70% → 10.6/14 | 34–47 | 44.0 | 24/24 | 10.0（28/35） | 2,636 ms | 2,986 ms |
| 大师 | 7×7 | 6/5/4/3/1 | 65% → 9.2/14 | 44–56 | 52.8 | 24/24 | 4.0（19/25） | 1,279 ms | 1,982 ms |

档位排的是「盘面多大」×「舰队多密」×「留下多少线索」，五档中位数严格单调
（`balance` 末尾还会按独立样本再量一次阶梯：`16.4 < 27.6 < 30.4 < 42.2 < 52.8`，
不单调就红）。分数是**推理步数的加权和**（每步按上表权重计），所以它同时反映盘有多大、
线索有多稀、要用到多贵的规则。`balance` 还盯住实测分位与 `band` 的偏差不许超过 35%。

出题耗时那一列要老实说：分布是**双峰**的——一次抽中的盘不到 1 ms，烧到抽取上限的盘要三秒，
所以中位数代表不了"点新的一局要等多久"。`budgetMs` 记的是**每档实测 p95 基线**，
门禁是"这一档的 p95 别比基线慢一倍"（`p95 > budgetMs × 2` 就红），绝对值每次照常打印。
高阶最慢那一盘 3.0 s，界面上有遮罩挡着，不让玩家对着不动的画布猜。

## 上线的到底是哪一批文件

这个仓没有构建步骤：浏览器加载的就是盘上这些文件，`Pages` 却只上传 `tools/assemble-site.sh`
拷进 `_site` 的那一份。于是有一条本地**结构性看不见**的坏法——页面后来引用了新文件，
而拷贝清单还停在旧的三行。这一轮就撞上了：`manifest.webmanifest`、`sw.js`、`assets/icons/*`
全都进了页面，却没有一条进 artifact，线上逐个 404，而仓里 119 项浏览器检查加引擎测试**一条都不红**，
因为没有任何一步在"清单只拷三个路径"的那个环境里加载过页面。PWA 那一层（可安装、离线打开）
在仓库里是完整的，在线上等于没写过——`js/pwa-register.js` 的注册失败是被 `catch` 静音的，
所以它连报错都不给。

现在的形状是：拷哪些文件只有 `tools/assemble-site.sh` 一处说得出，`pages.yml` 和本地闸调的是
同一支脚本，所以闸验的就是要上线的那份。`node tools/deploy-set.mjs`（`npm run deploy-set`）
跑四段共 36 条断言，钉在文件里的 `EXPECT_CHECKS = 18` 与 `EXPECT_ROWS = 36` 保证"闸自己缩水"
不可能伪装成绿：

- **A 同源**：`pages.yml` 必须确实在用那份共享清单，否则 CI 拷的是第二份清单，闸验的就不是上线那份。
- **B 可达**：`index.html` 的每个 `href`/`src`、manifest 的 `icons`/`screenshots`/`shortcuts`，
  以及 js 里 `new URL('sw.js', document.baseURI)` 这类**只在运行时才拼出来**的路径，
  逐个必须在产物里存在且非 0 字节。上一轮线上 404 的 `sw.js` 正是靠这一条才被看见的——
  只扫 HTML 的检查看不到它。0 条引用也算红（解析不到不等于全都齐）。
- **C 不许绝对路径**：`/sw.js` 这种写法会在 Pages 的 `/<仓名>/` 前缀下跳出项目站点。
- **D 位图不许说谎**：manifest 声明的 `sizes` 必须等于 PNG IHDR 里的真实宽高。

阴性对照跑过两次，都按预期红并点名缺的是哪个文件：从产物里挪走 `sw.js` → `B8` 红并且出处写
`js/pwa-register.js`（rc=1）；挪走 `assets/icons/icon-512.png` → `B8` 红并且出处写
`manifest.icons`（rc=1）；放回原字节后 rc 回到 0。这一段也进了 `tools/verify.sh`（在浏览器闸
之前跑，不占 Chrome）和 `ci.yml` 的 check job，`pages.yml` 里则对**即将上传的那个 `_site`**
再跑一次。

## 目录

```
index.html             一个 canvas + 侧栏读数 + 规则说明
css/game.css           全部颜色来自 theme.js 注入的 CSS 变量
js/engine/rng.js       字符串种子 → 确定性随机（盘只由 seed 决定，不含时钟与 Math.random）
js/engine/ships.js     模型、七条规则、nextDeduction、独立 verify/diagnose
js/engine/count.js     独立的逐格穷举计数器（唯一性的第二意见，不含推理规则）
js/engine/generate.js  种舰队 → 按"唯一且推得完"抹线索 → 按实测分数带抽盘 + 五档档位表
js/ui/game.js          状态机：手势、撤销、提示、判胜
js/render/board.js     几何 + 绘制 + 命中（线索画在盘外，缺数画菱形）
js/theme.js            配色与动效令牌（五档五配色）
js/audio/synth.js      WebAudio 合成音效，零音频文件
js/store.js            localStorage 单键存档：种子 + 墨（游程编码）+ 这一局的花费
js/main.js             装配、菜单、事件、window.battleship 调试面
tools/                 engine-test / balance / playtest(CDP) / scenarios / deploy-set / assemble-site / verify.sh
```
